# trabalho_chapeuzinho

Trabalho sobre o filme Deu a Louca na Chapeuzinho Vermelho

Produzido por:
Guilherme Diogo de Moraes
Kevin Cavalcante Silva

Este aplicativo informa ao usuário sobre o filme "Deu A Louca na Chapeuzinho Vermelho", uma animação
3d lançada no ano de 2005. Ela foi construída pensando no publico infantil, misturando personagens 
dos contos de fadas clássicos com personalidades únicas, como a Vovozinha que secretamente é uma 
esportista radical ou o Lobo Mal, que é um reporter assim como personagens originais da obra, como
o coelho Boingo, ou o ligeirinho
